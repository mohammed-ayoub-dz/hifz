#  Hifz (حفظ)

> An open-source, interactive Quran memorization app powered by gamification and gradual learning.

##  About
**Hifz** helps users memorize and retain the Quran through a step-by-step methodology:
* **Guided Repetition:** Read and repeat pages with interactive visual prompts.
* **Letter-by-Letter Validation:** Type verses with instant feedback on errors.
* **Full-Page Recapitulation:** Write complete pages to receive an accurate retention score.
* **Gamification:** Stay motivated with daily **Streaks** and a Duolingo-style **Hearts** system.

---

##  Tech Stack
* **Frontend:** Next.js + Framer Motion + Tailwind CSS
* **Backend:** Go (Golang) + Fiber v3 + GORM
* **Database:** PostgreSQL
